МОЙ ПУТЬ 2.0.1 — тренировки, питание и статистика
================================================

ЧТО ДОБАВЛЕНО
- Четыре приёма пищи: завтрак, обед, перекус, ужин. Любое количество продуктов,
  ввод граммов, редактирование и удаление порций.
- Калории, белки, жиры, углеводы, клетчатка, омега-3, витамины и минералы.
  Проценты личных целей, история их изменений и отметки неполного состава.
- 7793 продукта USDA SR Legacy доступны без сети после первой загрузки.
  Распространённые продукты ищутся по русским словам; часть названий английская.
  Вкладка «Магазин» ищет товары в Open Food Facts по названию или штрихкоду.
  В «Мои» можно сохранить собственный продукт с составом на 100 г.
- Вес тела по дням, графики любого нутриента и нагрузки по каждому упражнению.
  Период: 7/30/90 дней, всё время или свои даты. Для рабочих весов сравнивается
  максимальный вес выполненного подхода в первой и последней тренировках периода.
  Повторы видны рядом; рост нагрузки не приравнивается к росту силы.
- Полная копия JSON, импорт прежнего JSON и CSV истории тренировок.

ОБНОВЛЕНИЕ И СТАРЫЕ ЗАПИСИ
1. В старой версии сначала скачай резервную копию в разделе «Данные».
2. Размести все файлы новой версии на прежнем HTTPS-адресе приложения.
   Включи папку foods целиком. Сборка и серверная база данных не нужны.
3. Открой приложение с интернетом. Для загрузки справочника нужно около 5 МБ.
   После первой загрузки закрой приложение и открой снова; при необходимости
   обнови страницу ещё раз, чтобы применился новый офлайн-кеш.
   Если видишь старую кнопку «Загрузить копию», открой на том же адресе
   index.html?update=2.0.1 — например,
   https://waloldya.github.io/moy-put-tracker/index.html?update=2.0.1
   Ссылка загружает новую версию с сохранением данных на этом устройстве.
4. На том же устройстве и адресе прежние тренировки остаются в своём хранилище.
   Для переноса открой «Данные» → «Загрузить JSON или CSV», выбери свою копию,
   проверь предварительные итоги и нажми «Объединить записи».
5. Повторная загрузка той же копии не дублирует подходы и записи питания.
   Существующие выполненные подходы, вес и записи еды сохраняются при конфликте.
   Для переноса целей из JSON есть отдельный флажок. Если цели уже менялись,
   он по умолчанию выключен. CSV содержит только отмеченные выполненные подходы,
   без черновиков и исходного времени завершения тренировки.

КАК ПОЛЬЗОВАТЬСЯ
- «Питание» → выбери дату → «+» у приёма пищи → найди продукт → укажи граммы.
  Для изменения порции нажми на её строку. Личный продукт создаётся из поиска.
- «Цели» задаёт дневные ориентиры. Их можно ввести вручную или загрузить
  отдельным файлом JSON через «Данные». Личные настройки не входят в публичный
  код. Пока цель не задана, её процент не рассчитывается. При переносе настроек
  проверь флажок «Загрузить также цели из копии».
- Неизвестный нутриент обозначается «нет данных». Знак ≥ показывает сумму
  только известных значений. Пропущенные дни не считаются нулевым питанием.
  Справочники не гарантируют полный состав каждого продукта или наличие товара.
- Различай сырой, сухой и приготовленный продукт. Для товара с составом на
  100 мл приложение попросит плотность: миллилитры не заменяются граммами.
- Внизу дневника можно записать вес тела и в день без тренировки.
- «Данные» → «Скачать полную копию» сохраняет тренировки, питание, продукты,
  вес и цели. Копия нужна для переноса на другое устройство.

ХРАНЕНИЕ И УСТАНОВКА
Записи хранятся локально, без аккаунта и облачной синхронизации. Дневники не
отправляются на сервер; при поиске в Open Food Facts передаётся поисковый запрос.
Удаление данных браузера или приложения может удалить историю без копии.
Если данные изменились в другой вкладке, перезагрузи приложение перед вводом.

Для iPhone: открой HTTPS-адрес в Safari → «Поделиться» → «На экран Домой».
Одиночный HTML-файл через «Файлы» не подходит для загрузки справочника и кеша.
Без интернета работают тренировки, дневник и загруженный справочник USDA;
магазинный поиск требует сеть. Источники и лицензии описаны в SOURCES.md.

ДЛЯ РАЗРАБОТКИ
Статическое приложение без зависимостей на стороне пользователя.
Локальный запуск: python -m http.server 8765, затем http://localhost:8765.
Расчёты, преобразование единиц, импорт и защита хранилища: npm test.
Браузерный сценарий требует Playwright и Chromium:
  npm install --no-save playwright
  npx playwright install chromium
  npm run test:browser
  npm run test:update
Сценарий сам запускает временный HTTP-сервер. При необходимости можно задать
CHROMIUM_PATH, PLAYWRIGHT_MODULE или MOY_PUT_URL. Скриншоты попадают в test-results/.
Восстановление каталога: python scripts/build-food-catalog.py path/to/archive.zip.
Не добавляй личные резервные копии и дневники в публичный репозиторий.

Дневник финансов запланирован отдельным следующим этапом.
