МОЙ ПУТЬ — мобильное веб-приложение для iPhone 13 mini
===============================================

СОДЕРЖИМОЕ
- index.html: стартовая страница
- style.css: мобильный дизайн
- data.js: программа ТЯНИ / КАЛИСТЕНИКА / ТОЛКАЙ и техника 7 упражнений
- app.js: дневник, таймер, история, экспорт
- manifest.webmanifest, sw.js, icons/: установка на главный экран и работа без сети

КАК ОТКРЫТЬ
1. Для ознакомления можно открыть index.html в браузере на компьютере после распаковки.
2. Для использования в качестве полноценного приложения на iPhone необходимо выложить ВСЮ папку на HTTPS-сайт.
   Простой вариант: GitHub Pages или Netlify Drop (загрузить папку со всеми файлами).
3. Открой полученную ссылку В SAFARI на iPhone 13 mini.
4. Нажми «Поделиться» -> «На экран Домой» -> «Добавить».
5. Открой значок «МОЙ ПУТЬ» на главном экране.

ВАЖНО
- Записи хранятся локально на устройстве (localStorage), без аккаунта и синхронизации.
- Экспортируй резервные копии в разделе «Данные» после каждой недели.
- Удаление данных Safari или смена устройства могут удалить историю без копии.
- Нужен HTTPS для полноценной установки и автономной работы через service worker.
- При открытии одиночного HTML через предпросмотр Файлов iPhone могут быть ограничения на сохранение.
- Excel-дневник не синхронизируется автоматически с приложением. Можно экспортировать историю в CSV.
